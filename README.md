# FACEIT Vladivostok Server Router

この拡張機能は、極東地域やアジア圏のプレイヤーの遅延（Ping）を軽減するため、FACEITプラットフォームのウラジオストクにあるサーバーへのルーティングおよび強制接続を行うために設計されています。

> **⚠️ 重要:** 
> 安定したマッチメイキングのために、**パーティー（ロビー）内のすべてのメンバーがこの拡張機能を入れている必要があります！**

## 主な機能
- リージョンサーバーの強制フィルタリングと選択
- パケットロスとPingを削減するためのネットワーク経路の最適化
- ブラウザから直接動作する軽量な拡張機能

---

## 🌐 事前準備（リージョン変更とVPN）

拡張機能を使用する前に、以下の設定を行ってください（**ロビー内のメンバー全員**が対象です）：

1. **リージョンを EU に変更**
   * FACEITの設定から、マッチメイキングのリージョンを **EU** に変更します。
2. **VPN の接続（ロシアサーバーが表示されない場合）**
   * EUリージョンに変更してもロシアのサーバーがリストに表示されない場合は、**ロシア** または **カザフスタン** のVPNに接続してください。
   * 無料のVPNが必要な場合は、[VPNGate](https://www.vpngate.net/ja/) などでロシアのサーバーを見つけることができます。

## 📥 インストール方法

この拡張機能はストアで公開されていないため、デベロッパーモードを使用して手動でインストールします。

1. **ZIPファイルの解凍**
   * [Releases](https://github.com/zloybik/Only-Vladivostok-Server-Faceit/releases) から `faceit-ping-override.zip` をダウンロードし、任意のフォルダーに解凍します。

2. **拡張機能ページを開く**
   * Google Chrome の場合は、アドレスバーに `chrome://extensions` と入力して開きます。
   * Microsoft Edge の場合は、アドレスバーに `edge://extensions` と入力して開きます。

3. **開発者モードを有効にする**
   * 画面の右上（または隅）にある **「デベロッパー モード」** のスイッチをオンにします。

4. **拡張機能を読み込む**
   * 左上に表示される **「パッケージ化されていない拡張機能を読み込む」**（Edgeの場合は **「展開して読み込み」**）ボタンをクリックします。

5. **フォルダーの選択**
   * 手順1で解凍したフォルダの中にある、`faceit-ping-override` フォルダーを選択して開きます。

6. **FACEITの再読み込み**
   * ブラウザで FACEIT のページを開いているタブに移動し、`Ctrl + Shift + R`（Macの場合は `Cmd + Shift + R`）を押してページを完全に再読み込みします。

---

## 💡 プレイ時の注意点

- **検索のやり直し:** マッチ検索は **1分ごとにキャンセルしてやり直してください**。長時間放置すると、ノヴォシビルスクなど他のサーバーのロビーに飛ばされる可能性があります。
- **アジアサーバーに戻る場合:** 再びアジア（SEA）サーバーでプレイする際は、必ず拡張機能ページからこの拡張機能を **オフ** にしてください。
